Visualização dos usuários A equipe deverá criar ou ajustar a tela responsável pela listagem dos usuários cadastrados. A funcionalidade deverá: Buscar os usuários armazenados no banco de dados; Exibir os registros de forma organizada; Apresentar somente as informações que precisam ser visualizadas; Evitar a exposição de dados sensíveis ou desnecessários; Permitir identificar corretamente cada usuário; Integrar frontend, backend e banco de dados; Tratar possíveis erros durante a consulta. A equipe deverá analisar quais dados realmente precisam aparecer na listagem.
